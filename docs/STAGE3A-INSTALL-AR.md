# تعليمات تركيب المرحلة 3A (حسابات العملاء + PostgreSQL) — تجريبي فقط

**مهم:** لا يوجد مال حقيقي ولا دفع حقيقي ولا بريد حقيقي في هذه المرحلة. كل شيء في مخطط اسمه `sandbox`.

## 0) ما الجديد
- تسجيل العملاء وتفعيل البريد وتسجيل الدخول والخروج واستعادة كلمة المرور والملف الشخصي.
- قاعدة PostgreSQL (`miri-iran-db`) تحفظ الحسابات وسجل التدقيق.
- في لوحة الإدارة `/admin`: قسم «العملاء» (بحث وتقييد/إيقاف الحساب) وقسم «صندوق البريد التجريبي» (تفتح منه روابط التفعيل).
- إصلاح كلمة `null` في لوحة الأسعار، وإصلاح اتجاه الأسهم، وتسريع تحميل الموقع.

## 1) رفع الملفات إلى GitHub
1. فك ضغط `miri-iran-v6-wallet-stage3a.zip` على سطح المكتب.
2. افتح المستودع `miri-iran-v6` على GitHub، ثم **Add file** ثم **Upload files**.
3. اسحب **محتويات** المجلد (المجلدات `server` و`js` و`tests` و`tools` و`docs` و`.github` والملفات `package.json` و`index.html` و`wallet.css` و`CHANGELOG.md` و`.env.example`) واتركها تستبدل الملفات القديمة بنفس الأسماء.
4. اكتب في خانة الرسالة: `Wallet Stage 3A` ثم اضغط **Commit changes**.
5. المجلد `.github` (ملف `keep-warm.yml`) اختياري. إذا لم يظهر عندك بعد السحب فتجاهله.

## 2) إعدادات Render (Environment)
افتح خدمة الخادم في Render ثم **Environment** وأضف:

| الاسم | القيمة |
|---|---|
| `DATABASE_URL` | من `miri-iran-db` ثم **Connections** انسخ **Internal Database URL** |
| `SESSION_PEPPER` | نص عشوائي طويل (الأمر بالأسفل) |
| `WALLET_ENV` | `sandbox` |
| `DB_SCHEMA` | `sandbox` |
| `FRONTEND_URL` | `https://hussein39993.github.io/miri-iran-v6/` |
| `MAIL_MODE` | `sandbox` |

متغيرات `UPSTASH_REDIS_REST_URL` و`UPSTASH_REDIS_REST_TOKEN` و`WALLET_ADMIN_*` موجودة عندك، ولا تغيّرها.

لتوليد `SESSION_PEPPER` اكتب في PowerShell (سطر واحد) وانسخ الناتج:
```
$b = New-Object byte[] 48; [System.Security.Cryptography.RandomNumberGenerator]::Create().GetBytes($b); [Convert]::ToBase64String($b)
```
لا ترسل هذه القيمة لأحد ولا تضعها في GitHub. تغييرها لاحقاً يسجّل خروج كل العملاء.

## 3) أمر البناء (مهم جداً)
المشروع صار يستخدم مكتبة `pg`. في Render افتح **Settings** ثم **Build Command** واكتب: `npm install` (إذا كان فارغاً أو مختلفاً). ثم اضغط **Manual Deploy** ثم **Deploy latest commit**.

## 4) التأكد أن كل شيء يعمل
1. افتح `https://miri-iran-v6.onrender.com/api/health` وتأكد أن `build` هو `2026-11-28-wallet-3a`.
2. افتح `https://miri-iran-v6.onrender.com/api/health/db` وتأكد من `"status":"ready"` و`"environment":"sandbox"` وأن `migrations.pending` يساوي `0`.
3. في سجلات Render (Logs) يجب أن ترى `Accounts ready (sandbox)`.
4. إذا ظهر `"status":"disabled"`: متغير ناقص (راجع الجدول). إذا ظهر `"status":"error"`: انظر السجلات (غالباً `DATABASE_URL` خاطئ أو `npm install` لم يُنفَّذ). الخادم يعيد المحاولة كل 20 ثانية، وباقي الخدمات (الطيران والفنادق والتاكسي والمحفظة) تعمل بشكل طبيعي في كل الحالات.

## 5) اختبار يدوي من الموقع
1. افتح الموقع ثم **الملف الشخصي** ثم **إنشاء حساب** وسجّل بريداً وكلمة مرور (10 أحرف على الأقل).
2. افتح `https://miri-iran-v6.onrender.com/admin` وادخل، ثم قسم **صندوق البريد التجريبي** وافتح رابط التفعيل.
3. ارجع وسجّل الدخول، وجرّب تعديل الاسم وتغيير كلمة المرور والخروج.
4. جرّب **نسيت كلمة المرور؟** (الرابط يظهر في الصندوق التجريبي).
5. في قسم **العملاء** جرّب «إيقاف» حساباً مع كتابة السبب، ثم حاول الدخول به (يجب أن يُرفض).

## 6) الاختبارات
**أ) اختبارات بدون قاعدة بيانات (محاكاة)** — تثبت المنطق فقط ولا تنفذ SQL:
```
npm install
```
```
npm run test:accounts
```
**ب) اختبار حي على PostgreSQL الحقيقي** — ينفذ SQL الحقيقي. ينشئ مخططاً مؤقتاً `sandbox_test_xxxx` ويحذفه بعد الانتهاء، ولا يلمس مخطط `sandbox`. من حاسوب Windows استخدم **External Database URL**:
```
$env:DATABASE_URL="ضع هنا External Database URL"
```
```
$env:DATABASE_SSL="require"
```
```
npm run test:live
```
إذا رفض الاتصال: في Render افتح `miri-iran-db` ثم **Access Control** وتأكد أن الوصول الخارجي مسموح.

## 7) أوامر قاعدة البيانات اليدوية (اختيارية)
الخادم يطبّق التحديثات تلقائياً عند التشغيل. للتشغيل اليدوي (بعد ضبط `DATABASE_URL` كما في الأعلى):
```
npm run db:status
```
```
npm run db:migrate
```

## 8) التراجع عند حدوث مشكلة
- **الأسرع:** في Render افتح **Deploys** واختر النشر السابق ثم **Rollback**.
- **من GitHub:** افتح آخر Commit ثم **Revert**.
- **تعطيل الحسابات فقط:** احذف المتغير `DATABASE_URL` من Render. الموقع يعمل كما كان وتبقى الحسابات متوقفة.
- **حذف كل البيانات التجريبية (لا رجعة فيه):**
```
npm run db:drop-sandbox -- --yes-delete-sandbox-data
```
المخطط `sandbox` منفصل، ولا يتأثر طيران ولا فنادق ولا تاكسي ولا أسعار الصرف.

## 9) تنبيه: انتهاء قاعدة البيانات المجانية
قاعدة Render المجانية تنتهي في **27 ديسمبر 2026**. قبل ذلك رقّها أو انقل البيانات. دليل النسخ الاحتياطي والاستعادة الكامل يأتي في المرحلة 3D. بيانات هذه المرحلة تجريبية فقط.

## 10) أول زيارة بطيئة (Cold Start)
Render المجاني ينام بعد نحو 15 دقيقة. الموقع الآن يظهر فوراً، وتظهر رسالة «الخادم يستيقظ» ثم تصل الأسعار. وللتخفيف: الملف `.github/workflows/keep-warm.yml` يزور الخادم كل 10 دقائق (اختياري؛ احذفه لإيقافه). لإنهاء المشكلة نهائياً يلزم خطة مدفوعة.

## 11) ما لم يتم بعد
المحافظ الحقيقية وسجل القيد المزدوج (3B)، الإيداعات والإيصالات ولوحة الإدارة الكاملة (3C)، الأدوار والتحقق الثنائي وتحسينات الأمان والأداء الإضافية (3D)، وإرسال بريد حقيقي (Resend أو Brevo لاحقاً).
